User Guides
===========

The usage guide is the place to start: it explains the procedure and
gives a recipe for each part of the library. *End-to-End* follows one
simulated experiment from raw data to certified claims: fitting an
uplift model, distilling it into a decision tree, and testing and
pruning the tree with trickle down. *Reproducing the Paper* works through the
calculations of [Wil26]_ in the paper's order.
