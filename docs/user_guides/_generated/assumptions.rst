**Outcome predictors**
   x0 ~ N(0, 1); x1 uniform on {0, 1, 2}. The paper says only 'continuous' and 'three-level categorical'; these follow the author's earlier simulation script.

**Effect moderators**
   x2 and x3 independent fair coins, which gives the paper's 'split the population evenly across the four moderator levels'.

**Effect noise**
   epsilon_1 ~ N(0, 9), independent of epsilon_0: the paper states epsilon_0 ~ N(0, 9) and then only that epsilon_1 is independent of it, which we read as the same distribution. This choice was made after a pilot: N(0, 1) gave every procedure more power than the paper reports, uniformly, by about the factor the extra variance of N(0, 9) removes. It is the one assumption calibrated against the paper's results.

**Treatment assignment**
   Independent Bernoulli(1/2) per individual ('with equal probability').

**Training and evaluation halves**
   A uniformly random split into two halves of equal size.

**T-learner**
   scikit-learn HistGradientBoostingRegressor(max_iter=200, max_depth=4, learning_rate=0.1) on each arm. The paper names no learner; the author's earlier script used XGBoost with the same settings, which needs OpenMP and is slower to run 4,000 times.

**Summary tree**
   scikit-learn DecisionTreeRegressor(max_depth=3, min_samples_leaf=0.01): 'a hundredth of the sample' read as 1% of the training half the tree is fit on.

**Node estimates**
   tau_train is the difference of arm means in the node on the training half, which is what chooses each direction.

**Fixed partition**
   The true moderator structure: split on x2, then on x3 within each half, giving 7 nodes and 10 hypotheses. This matches the paper's 'ten true claims available' and Table 4's 2 / 4 / 4.

**Global null**
   tau = 0 for everyone, so every hypothesis in every hierarchy is true and the FWER is the chance of rejecting anything.

**Effect scale**
   Every subgroup's tau multiplied by the scale; 1.00 is the unscaled configuration.

**Every subgroup helped**
   The harmed quarter's tau of -1.00 replaced by +0.30, the value the author's earlier simulation script used for that cell. Chosen after a pilot of 1,000 replications per cell, scored against all 30 cells of the paper's lower Table 3: +0.30 fit best (mean squared z of 1.7) among 0.00, 0.30, 0.50 and 1.00 (2.7, 3.6 and 31.2). +1.00, the first value we tried, left the x3 split within x2 = 0 with a contrast of only 0.2, and fixed hierarchy far below the paper.

**True claims**
   A rejection counts as a true claim only if its null is false under the direction actually tested. A one-sided rejection in the wrong direction is a Type I error, not a claim. A two-sided rejection of a false null counts, as the paper says Table 3 'credits both procedures for reaching a node'.

**Splits too small to test**
   If either arm of a node holds fewer than two evaluation observations, the split above it is dropped and its parent becomes a leaf. With leaves of 1% this almost never happens.
